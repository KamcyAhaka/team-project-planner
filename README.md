# Team Project Planner (WDD430 - Team 11)

## Project Description

Team Project Planner is a web application that helps student teams organize and manage collaborative projects in one place. Users can create projects, assign tasks to team members, track task progress, and monitor deadlines through a simple and responsive interface. The application is designed for students working on group assignments or collaborative projects.
